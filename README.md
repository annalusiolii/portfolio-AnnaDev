# Portfólio Pessoal — Anna Lusioli

**Nome da aluna:** Anna Lusioli

## 1. Descrição do portfólio

A ideia de criar esse portfólio foi reunir um pouco de quem eu sou e das coisas que fazem parte da minha trajetória. Não quis apresentar somente minhas experiências e aprendizados na área da tecnologia, mas também trazer um pouco das minhas experiências de vida, dos meus interesses e de outras áreas com as quais tenho contato, como arte, dança, comunicação e produção audiovisual.

Acredito que todas essas experiências fazem parte de quem eu sou e também influenciam a maneira como penso, crio e desenvolvo projetos. Por isso, quis construir um espaço que representasse essa diversidade, mostrando que meus interesses vão além de uma única área.

## 2. Tecnologias utilizadas

Para desenvolver o projeto, utilizei:

- **HTML5:** para criar a estrutura e organizar as informações da página.
- **CSS3:** para desenvolver a identidade visual, cores, organização dos elementos e adaptação para diferentes telas.
- **Bootstrap 5:** para auxiliar na responsividade e na construção do menu de navegação.
- **JavaScript:** utilizado no funcionamento do menu responsivo do Bootstrap.
- **Google Fonts:** para utilizar a fonte JetBrains Mono.
- **Git e GitHub:** para versionar e armazenar o projeto.
- **GitHub Pages:** para publicar o portfólio na internet.

O desenvolvimento foi realizado no meu MacBook Air, utilizando o Terminal do macOS para criar pastas, organizar arquivos, escrever e editar os códigos e realizar o envio do projeto para o GitHub.

## 4. Funcionamento do projeto

O portfólio funciona como uma página única, dividida em algumas seções para facilitar a navegação. No menu principal, é possível acessar o início, meu perfil, meus projetos, minha trajetória e meus contatos.

Na página inicial, apresento meu nome e uma breve introdução. Na parte do perfil, falo um pouco sobre minha formação, meus interesses e as tecnologias e ferramentas que utilizo. Na seção de projetos, reúno alguns trabalhos e atividades que desenvolvi durante meus estudos e também projetos relacionados às minhas experiências criativas.

A seção de trajetória apresenta um pouco do meu caminho acadêmico e profissional, enquanto a parte de contato disponibiliza links para que as pessoas possam falar comigo por e-mail ou acessar minhas redes.

A navegação acontece por meio dos links do próprio menu, que direcionam o visitante para cada parte da página.

## 5. Descrição do recurso novo adicionado

Como recurso adicional, decidi criar uma seção chamada **"Minha trajetória"**, utilizando o formato de linha do tempo.

Escolhi adicionar essa parte porque queria que o portfólio tivesse algo além da apresentação tradicional de perfil, habilidades e projetos. Achei interessante ter um espaço para mostrar um pouco do caminho que venho construindo, reunindo minha formação na tecnologia e minhas experiências com arte e comunicação.

Assim, a linha do tempo ajuda a representar melhor a diversidade de áreas que fazem parte da minha vida.

## 6. Como o recurso foi implementado

A seção foi implementada utilizando HTML5 e CSS3. Primeiramente, foram criados elementos HTML para representar cada etapa da trajetória, organizados dentro de uma estrutura principal.

Em seguida, utilizei CSS para construir a aparência visual da linha do tempo, aplicando uma linha vertical lateral, marcadores circulares para identificar cada etapa e estilos próprios para os títulos e descrições.

Também foram utilizadas as cores da identidade visual do portfólio, principalmente rosa e roxo, mantendo a unidade visual com as demais seções da página.

Dessa maneira, foi possível desenvolver um recurso visual adicional ao modelo inicial, utilizando elementos de estruturação e estilização para organizar e apresentar as informações de forma mais clara.
